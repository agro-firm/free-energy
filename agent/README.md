# Agent System

This directory contains the operating rules for the integrated 20-cow dairy + biogas + fertilizer + solar project.

## Mandatory routing
Before any design, calculation, image, implementation, cost, or review task:
1. Read agent/skill/00-master-plant/SKILL.md.
2. Read agent/skill/01-engineering-math/SKILL.md.
3. Read the subsystem skill or skills involved.
4. For images, also read agent/skill/15-visualization-images/SKILL.md.
5. For any accepted change, run agent/skill/18-construction-review/SKILL.md.

Never silently change a dimension, equipment capacity, process order, or material flow.
