# Design Level Framework

## Hierarchy
1. surveyed existing ground.
2. verified flood/high-water reference.
3. road/gate tie-in.
4. outfall/headwater.
5. finished site grading.
6. section FFL/process levels.
7. drain inverts.
8. foundation/excavation levels.

## Project design rules
These are internal planning criteria, not code claims.

### Clean/dry rooms
Office, feed store, milk room, water pump bay:
```
FFL >= max(adjacent finished grade +0.150 m, design flood reference +0.300 m)
```

### Generator/electrical
```
FFL >= max(adjacent grade +0.150 m, design flood reference +0.450 m)
```
Critical panels may require additional mounting height.

### Gas storage/treatment
Slab:
```
>= max(adjacent grade +0.150 m, design flood +0.300 m)
```
subject to hazardous-area review.

### Cow shed
Dry/high floor lines:
```
~+0.100 m minimum over adjacent external grade
```
with internal manure slopes coordinated to Section 07.

### Cow yard
Contained dirty pavement with positive slope to dirty drain; avoid importing clean stormwater.

### Waste/fertilizer wet process
Curbed process slab:
```
~+0.100 m over adjacent clean access
```
with local 1–1.5% internal fall to dirty collection.

### Digester compound
Compound kept above ponding/flood risk; vessel internal bottom remains Section 08 local geometry relative to final compound FGL.

## Gate
Gate grading must connect road and site without creating an inward stormwater chute.
