# 07 — Waste Receiving + Mixing

## Status
Planning baseline. Detailed construction design will be added later.

## Baseline
Approximately 140 ft²

## Purpose
Receives automatically collected manure, removes debris, mixes dilution water and meters slurry into the digester.

## Inputs
Collected dung from scraper/gutters and measured process water.

## Outputs
Homogeneous slurry to the biogas digester.

## Interfaces
Cow shed manure automation, water system and digester.

## Current design notes
Current planning flow is about 270 kg/day collected dung and roughly 0.54 m³/day slurry at the current 1:1 dilution assumption.
