# Tax / VAT / Duty Control

## Rule
No universal tax percentage is applied to all packages.

Different goods/services can have different treatment.

## Imported equipment
For every import:
1. confirm HS code.
2. use Bangladesh Customs/NBR live tariff.
3. identify CD/RD/SD/VAT/AIT/AT as applicable.
4. confirm exemptions/SRO if any.
5. obtain C&F estimate.

Official live references:
- https://customs.gov.bd/portal/services/tariff/tableOfContents.jsf
- https://nbr.gov.bd/budget/tariff-schedule/eng

## Local vendor quotes
Require quote to state:
- VAT included/excluded.
- taxes included/excluded.
- withholding treatment.
- transport.
- installation.
- registration/service fees.
