# Data Logging and Digital Records

## Automatic
Preferred:
- water.
- slurry batches.
- gas flow.
- holder level.
- H₂S.
- generator.
- solar.
- alarms.

## Manual
- cow health.
- milk.
- feed.
- medicine.
- cleaning.
- fertilizer.
- maintenance.

## Data quality
Every record includes:
- timestamp.
- operator/system.
- unit.
- status.
- exception.

## Backup
- daily cloud/server sync if available.
- monthly offline/export backup.
- controlled user accounts.

## Correction
Never silently overwrite.
Record:
- original.
- correction.
- reason.
- user.
- date.
