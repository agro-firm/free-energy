# Feed Store — Engineering Math Workbook

## 1. Room area
```
18 × 20 = 360 ft²
360 × 0.09290304 = 33.4451 m²
```

## 2. Room volume
At 12 ft clear height:
```
360 × 12 = 4,320 ft³
4,320 × 0.0283168 ≈ 122.33 m³
```

## 3. Herd dry-matter reference
```
20 cows × 12 kg DM/day = 240 kg DM/day
```

This is a herd nutritional planning reference, not an instruction that all 240 kg/day is stored indoors as one material.

## 4. Concentrate quantity
Existing project monthly concentrate budget:
```
Tk 110,700 / 30 = Tk 3,690/day
```

Current 2026 public cattle-feed examples are roughly Tk60–66.5/kg for branded dairy feed.

At Tk60/kg:
```
3,690 / 60 = 61.5 kg/day
```

At Tk66.5/kg:
```
3,690 / 66.5 ≈ 55.49 kg/day
```

Rounded storage-design assumption:
```
60 kg/day
```

Seven days:
```
60 × 7 = 420 kg
```

25 kg bags:
```
420 / 25 = 16.8 → 17 bags
```

50 kg bags:
```
420 / 50 = 8.4 → 9 bags
```

## 5. Concentrate inventory value
At Tk60/kg:
```
420 × 60 = Tk 25,200
```

At Tk66.5/kg:
```
420 × 66.5 = Tk 27,930
```

At a broader current animal-feed reference of Tk72.5/kg:
```
420 × 72.5 = Tk 30,450
```

## 6. Dry roughage
Assumption:
```
4 kg/cow/day × 20 = 80 kg/day
```

Seven days:
```
80 × 7 = 560 kg
```

Assume baled bulk density 120 kg/m³:
```
560 / 120 = 4.667 m³
```

Allocated bay floor area:
```
8 × 10 = 80 ft²
80 × 0.09290304 = 7.432 m²
```

At average stack height 1.5 m:
```
7.432 × 1.5 = 11.148 m³ gross
```

Even after access/air-clearance losses, the zone has substantial reserve.

## 7. Mineral/premix
Assume:
```
0.15 kg/cow/day × 20 = 3 kg/day
```

30 days:
```
3 × 30 = 90 kg
```

The secure 4×4 ft zone is more than adequate by volume; organization and segregation are more important than bulk capacity.

## 8. Fresh green forage
Assumption:
```
15 kg/cow/day × 20 = 300 kg/day as-fed
```

Two-day maximum temporary staging:
```
300 × 2 = 600 kg
```

This belongs primarily under Section 06 / same-day feeding, not long-duration Section 05 storage.

## 9. Average storage loading
Concentrate zone:
```
420 kg / 7.432 m² = 56.51 kg/m² average
```

Roughage zone:
```
560 / 7.432 = 75.35 kg/m² average
```

These averages are low, but rack/pallet **point loads** can be much higher. Structural floor design uses actual rack loads.

## 10. Ventilation
Room volume:
```
122.33 m³
```

At 4 ACH planning:
```
122.33 × 4 = 489.32 m³/h
```

In cfm:
```
489.32 / 1.699 ≈ 288 cfm
```

Concept ventilation: **~300–500 cfm**, screened and rain-protected.

## 11. Electrical connected load — concept
- two exhaust fans: 2 × 0.15 = 0.30 kW
- six LED lights: 6 × 0.018 = 0.108 kW
- dehumidifier allowance: 0.50 kW
- scale/data: 0.03 kW
- optional closed mixer: 1.50 kW

Without optional mixer:
```
0.30+0.108+0.50+0.03 = 0.938 kW
```

With optional mixer:
```
0.938+1.50 = 2.438 kW
```
