# Biogas Digester — Process Design

## 1. Hydraulic design
Daily feed:
```
0.54 m³/day
```

Minimum 30-day hydraulic volume:
```
0.54 × 30 = 16.2 m³
```

Selected target:
```
20 m³
```

Resulting HRT:
```
20 / 0.54 = 37.04 days
```

This provides hydraulic margin while staying inside the 25 m³ total vessel.

## 2. Vessel volume split
```
25 m³ total
20 m³ working liquid
5 m³ headspace/freeboard
```

Headspace is **process buffer**, not the farm's primary gas storage. Section 09 remains the main raw-gas holder.

## 3. Feed total solids
Fresh dung TS planning assumption:
```
270 kg/day ×19%
=51.3 kg TS/day
```

After adding ~270 kg/day water:
```
slurry mass ≈540 kg/day
```

TS concentration:
```
51.3 / 540 ×100
≈9.5% TS
```

This is a workable planning solids level for pumpable cow-dung slurry, but actual manure TS must be measured.

## 4. Organic loading
Assume VS = 80% of TS:
```
51.3×0.80
=41.04 kg VS/day
```

At 20 m³ working volume:
```
41.04 / 20
=2.052 kg VS/m³·day
```

This is an engineering planning check, not a guaranteed biological operating limit.

## 5. Mixing / recirculation
Base concept uses **external periodic recirculation**, not an inaccessible permanent internal mixer.

Advantages:
- pump remains serviceable outside vessel
- reduces internal moving parts
- allows sample/flush connection
- can help limit settling/scum

Recirculation schedule must be tuned from actual solids behavior. Continuous mixing is not assumed.

## 6. Feed
Section 07 provides four ~0.135 m³ batches/day.

Feed inlet remains submerged to:
- reduce gas escape
- reduce crust disturbance
- avoid splash/aerosol
- limit oxygen entry

## 7. Digestate discharge
The digester operates near constant liquid level.

Each feed batch displaces approximately equal digestate volume:
```
≈0.135 m³/feed
≈0.54 m³/day
```

Digestate goes by controlled gravity/overflow to Section 12.

## 8. Gas production
Planning:
```
270 kg/day ×0.030
=8.10 m³/day
```

Good-operation case:
```
270×0.034
=9.18 m³/day
```

Methane planning fraction:
```
~60%
```

Gas exits the roof to primary condensate protection then Section 09.

## 9. Gas pressure
This is a **low-pressure digester**, not a pressure storage vessel.

Required:
- pressure/vacuum relief
- pressure indicator/transmitter
- gas-tight roof
- safe relief discharge
- no shutoff valve between vessel and required relief device unless engineered bypass/redundancy preserves protection

Setpoints are ENGINEER/VENDOR.

## 10. Temperature
Planning unheated range:
- desirable operation ~25–35°C
- monitor daily
- semi-buried geometry moderates temperature swings

If sustained temperature is too low for stable gas production, heating/insulation becomes a future change requiring recalculation.

## 11. pH
Planning operating band:
```
~6.8–7.5
```

pH trends matter more than one isolated reading.

## 12. Scum/settling
Control strategy:
- good upstream mixing/screening
- periodic recirculation
- manway for shutdown cleaning
- no large bedding/plastic feed
- monitor differential behavior through gas rate, volume and sludge accumulation

## 13. Sampling
Provide accessible sample point on recirculation/digestate line.
Do not open gas-space manway for routine sampling.
