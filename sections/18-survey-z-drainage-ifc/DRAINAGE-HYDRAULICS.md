# Drainage Hydraulics

## Manning equation
```
Q = (1/n) A R^(2/3) S^(1/2)
```

## Screening pipe
Assume:
- circular pipe D=0.200 m.
- n=0.013.
- S=1%=0.01.
- full flow.

```
A=πD²/4
=0.03142 m²
R=D/4
=0.050 m
```

```
Q≈0.0328 m³/s
≈32.8 L/s
```

This exceeds the 14.34 L/s 100-mm/h screening runoff by >2×.

## 150 mm comparison
At same n and 1%:
```
Q≈15.2 L/s
```

It is too close to the screening flow to serve as a comfortable full-site clean trunk after debris/backwater/freeboard allowances.

## Concept recommendation
A 200 mm clean storm trunk is a reasonable **screening starting point**, not a final design.

Final system may instead use:
- Section 14 covered open drain.
- larger pipe.
- multiple branches.
- catch basins.
- flap/check arrangement.
- pumping if gravity outfall is impossible.

## Backwater
Receiving-water high level may reduce or reverse capacity. Final hydraulic grade line must be checked.
