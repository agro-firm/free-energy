# Water Utility — Operating Process

## Normal
source → ground tank → duty pump → pressure manifold → farm branches + overhead-tank refill.

## Tank control
If OHT low:
- start duty pump
- fill until high
- alternate duty pump next cycle

If duty pump fault:
- start standby
- alarm

## Ground tank low
- inhibit pumps before dry-run
- alarm
- ration noncritical wash loads
- protect drinking water

## Power failure
- OHT gravity line remains available
- suspend washdown
- prioritize cow drinking and hygiene

## Leak/high flow
- alarm on abnormal overnight/continuous flow
- isolate branch if required

## Water-quality alarm
If source test fails:
- stop potable use
- switch to safe backup source/treatment
- do not use failed water for milk cleaning
