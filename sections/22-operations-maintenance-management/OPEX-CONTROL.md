# Operating Expense Control

## Principle
Section 22 does not hard-code staff salaries or volatile input prices without current quotes.

## Monthly quantity baselines
- saleable milk planning before rejection: ~4,200 L/30d.
- concentrate: ~1,800 kg.
- dry roughage: ~2,400 kg.
- fresh forage: ~9,000 kg as-fed.
- water: ~99 m³ normal.
- biogas: ~243–275 m³.
- gross biogas electricity: ~436–494 kWh.
- solar: ~1,750.5 kWh planning.
- solid fertilizer base: ~1,160 kg.

## Cost per liter
```
OPEX per saleable L =
total monthly operating expense
/
saleable milk L
```

## Feed cost per liter
```
monthly feed cost / saleable milk L
```

## Renewable offset
Track:
- self-consumed solar kWh.
- generator kWh.
- exported solar.
- grid import.

Do not value all generated kWh at the same tariff unless tariff/use is verified.
