# Pest and Vector Control

## Targets
- rodents.
- flies.
- mosquitoes.
- birds/insects where relevant.

## Prevention
- feed spill cleanup.
- sealed feed.
- drainage cleaning.
- vegetation control.
- screens.
- waste/manure movement.
- remove standing water.

## Traps/baits
Use mapped stations.
Protect from:
- cows.
- feed.
- milk.
- children/unauthorized persons.

## Chemical use
Only approved product/label instructions.
Record:
- product.
- location.
- quantity.
- date.
- operator.

## Disease event
Intensify vector control as vet/DLS guidance requires.
