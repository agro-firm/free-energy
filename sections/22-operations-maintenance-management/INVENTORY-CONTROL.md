# Inventory Control

## Classes
A — critical production/safety.
B — important maintenance.
C — normal consumable.

## Reorder point
```
ROP =
average daily use × replenishment lead time
+ safety stock
```

## Feed
Concentrate design stock:
```
~7 days
```

Dry roughage:
```
~7 days
```

Fresh forage:
daily / 1–2 day short staging.

## Medicines
FEFO.
No overstock beyond expiry/use capability.

## H₂S media
Reorder before lead-bed exhaustion using:
- H₂S trend.
- gas volume.
- vendor capacity.
- delivery lead time.

## Cycle count
- A weekly.
- B monthly.
- C monthly/quarterly as suitable.

## Stockout
P1 stockout is reported to manager immediately with continuity plan.
