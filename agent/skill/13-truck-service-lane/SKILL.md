# Truck / Service Lane Skill

## Baseline
- Width: 14 ft.
- Runs along one side of the 65 × 95 ft site.

## Must serve
- Milk pickup.
- Feed unloading.
- Fertilizer pickup.
- Generator/digester maintenance.
- Veterinary vehicle.
- Emergency access.

## Design checks
Gate width, swept path, reversing/turning strategy, canopy clearance, pavement loading, drainage, pedestrian separation and loading-door position.

## Rule
Do not use the truck path as permanent storage.
