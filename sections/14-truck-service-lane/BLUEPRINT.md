# Truck / Service Lane — Blueprint and Coordinate Specification

## Local coordinate system
- origin: front/building-side corner
- X=0–14 ft across lane, building/loading side → outer boundary/drain
- Y=0–95 ft front gate → rear utility end
- Z vertical

## Longitudinal stations
### STA 0–10
Gate/entry.
Keep completely clear.

### STA 10–35
Milk pickup zone.
Truck may stop centered/shifted outward.

### STA 35–60
Feed unloading node aligned with Section 06 canopy.

### STA 60–70
Transition/service-clear zone.

### STA 70–95
Fertilizer/rear utility/generator maintenance node.

## Cross-section
```text
X=0 BUILDING / LOADING SIDE
| painted ~4 ft loading/worker zone |
|      vehicle running surface       |
|                                    |
|------------------------------- drain X=14
Total width = 14 ft
```

No physical curb separates the painted strip in the baseline.

## Crossfall
From X=0 high side to X=14 drain side:
```
1.5%
```

Total fall:
```
14×0.015
=0.21 ft
=2.52 in
≈64 mm
```

## Drain
Covered/traffic-safe edge drain:
- X≈13.5–14 ft
- Y=0–95 ft
- concept width/depth ~300×300 mm
- final hydraulic size from rainfall/catchment

## Gate
At Y=0.
Clear width 14 ft minimum.
Preferred 16-ft boundary opening/flare if geometry permits.

## Design truck envelope
Reference long Tata LPT 709:
- length ≈22.56 ft
- width ≈7.07 ft
- height ≈7.68 ft cab/chassis reference
- GVW 7.5 t

Loading-zone lengths are 25 ft to contain the long reference vehicle with small longitudinal margin.
