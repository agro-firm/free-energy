# Workfront Release

A workfront is RELEASED only if:
- IFC/approved drawing.
- survey control.
- method statement.
- ITP.
- approved material.
- previous work accepted.
- permit/HSE controls.
- access.
- required vendor data.
- RFI critical issues closed.

## Status
- RED: not released.
- AMBER: conditional.
- GREEN: released.

## Examples
No digester wall pour before:
- base accepted.
- rebar approved.
- sleeves/waterstops checked.
- concrete source/mix accepted.

No solar installation before:
- roof structural signoff.
- mounting shop drawing.
- fall-protection plan.
