# Rooftop Solar — Architecture Report

## Roof geometry
Cow shed:
```
26×48 ft
```

Half-span:
```
13 ft
```

Rise:
```
5 ft
```

Slope length:
```
sqrt(13²+5²)
=13.928 ft
=4.245 m
```

Two roof planes:
```
2×48×13.928
=1,337.13 ft²
≈124.22 m²
```

## Array architecture
Each plane:
- one portrait module row
- 12 modules along 48-ft length
- module long side follows roof slope

Module row length:
```
12×1.134
=13.608 m
```

Roof length:
```
14.630 m
```

Remaining longitudinal:
```
1.022 m
≈0.51 m each end
```

Slope reserve:
```
4.245-2.382
=1.863 m
```

Use that reserve for ridge/eave ventilation, access and gutters.

## Visual strategy
Panels stay flush/parallel to roof rather than adding high tilt racks.
Benefits:
- lower wind uplift.
- simpler structure.
- preserves shed aesthetics.
- matches existing roof pitch.

## Inverter location
Mount near Section 11/electrical infrastructure in a shaded, ventilated, dry location, not inside animal splash/ammonia exposure if avoidable.

## Access
Provide:
- roof access point.
- ridge/eave service corridor.
- end clearance.
- cable route that does not create trip hazards.
