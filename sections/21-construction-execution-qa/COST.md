# Section 21 — Construction Management / Site Preliminaries Cost

## Status
This is an **optional/consolidated allowance**, not automatically added to the Tk269.73 lakh control budget.

Contractor preliminaries may already be embedded in awarded package prices, and Section 20 separately contains optional procurement/QS management.
