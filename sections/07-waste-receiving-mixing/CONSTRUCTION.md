# Waste Receiving + Mixing — Construction Plan

## Preconstruction
- survey cow-shed outlet elevation
- survey Section 08 digester inlet elevation
- confirm pump vendor
- confirm mixing-tank dimensions/load cells
- confirm slurry pipe route/head
- groundwater/soil check for below-grade sumps
- finalize containment and drainage

## Sequence
1. set out 10×14 ft
2. excavate RS-101 and ES-101
3. construct engineer-designed sump base/walls
4. waterproof/test sumps
5. install inlet/grit/screen structure
6. install dirty floor drains and pipe sleeves
7. pour process floor/curbs
8. erect roof/vented enclosure
9. install MT-101 frame/load cells
10. install P-101/M-101/P-102
11. install water/slurry piping
12. install flow meters/valves
13. install PLC/electrical
14. install sensors
15. dry I/O test
16. water commissioning
17. simulated slurry test
18. live manure commissioning
19. tune PLC batches

## Hold points
- sump reinforcement before pour
- waterproofing/leak test
- sump cover/load rating
- inlet/outlet elevations
- load-cell frame level
- pipe supports
- pump removal path
- flow-meter straight-run/vendor requirements
- electrical earthing
- PLC cause/effect test

## Commissioning
### Water test
Use clean water to verify:
- pumps
- levels
- valves
- emergency sump
- leaks
- flow meters
- interlocks

### Simulated slurry
Use safe thickened test medium if appropriate to verify no-flow/settling behavior before live manure.

### Live manure
Start at reduced batch size and verify:
- mixing
- pump current
- flow repeatability
- digester response
- odors/splashes
- screen loading

## As-built
Record exact:
- sump dimensions
- elevations
- pipe diameters
- valve tags
- cable routes
- PLC I/O
- setpoints
- pump curves
