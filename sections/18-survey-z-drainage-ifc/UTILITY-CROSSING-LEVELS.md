# Utility Crossing Levels

## Crossing register
Every buried crossing must record:
- utility.
- X/Y station.
- top/bottom elevation.
- cover.
- sleeve size.
- separation.
- marker.

## Service lane
Avoid crossings where possible.

If required:
- install sleeves before RCC pavement.
- no buried isolation valve under truck wheel path.
- provide tracer/marker.
- pressure/leak test before pavement.

## Water
Potable pipe must remain protected from dirty drain contamination and follow local code separation.

## Electrical/data
Use dedicated conduits/duct banks with spare capacity as designed.

## Gas
Prefer no service-lane crossing. If unavoidable, gas engineer defines depth/protection and hazardous considerations.

## Dirty drains
Never cross above potable water without engineered separation/protection.
