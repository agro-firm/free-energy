- footprint: 26 × 48 ft
- 2 rows × 10 cows
- width zoning: 3 / 5.5 / 1.5 / 6 / 1.5 / 5.5 / 3 ft
- 40 ft active stall run
- 4 ft cross/service zone at each end
- gable roof
- solar on shed roof as project target
- manure lanes outside cow rows
- central feed alley
- no gas equipment inside
