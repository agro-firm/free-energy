# ROI and Simple Payback

## Gross plant/control CAPEX
Tk26,972,958.

## Base scenario
EBITDA:
-Tk2,464,394/year.

Simple payback:
not meaningful because operating cash proxy is negative.

## Upside / target
EBITDA:
Tk1,354,886/year.

Plant-only simple payback:
26,972,958 / 1,354,886
≈ 19.91 years.

## Illustrative total-capital case
If all 20 cows are newly purchased and the 3-month working-capital reserve is funded:
Total illustrative capital = Tk33,361,083.

At upside EBITDA:
33,361,083 / 1,354,886
≈ 24.62 years.

## Milk price sensitivity
Using the same upside assumptions but Tk75/L milk:
EBITDA ≈ Tk1,855,666/year.

Plant-only payback:
≈14.54 years.

Illustrative total-capital payback:
≈17.98 years.

## Limitations
Simple payback ignores:
- financing.
- tax.
- replacement.
- degradation.
- inflation.
- residual value.
- time value of money.

Use NPV/IRR only after real cash-flow assumptions are available.
