# Generator and Electrical SOP

## Before run
- treated gas ready.
- holder level suitable.
- oil.
- battery.
- ventilation.
- CH₄/CO clear.
- room clear.
- ATS/breaker status.

## Normal gas cycle
Holder ready → ventilation → start unloaded → stabilize → ATS essential load → stage loads.

## Target
Normal:
```
~4 kW
```

Planning gas:
```
~2.23 m³/h
```

## Low gas
Shed Tier 2 → transfer normal source → cooldown → close gas → stop.

## Never
- backfeed grid.
- run untreated gas.
- run with exhaust leak.
- run with failed critical gas/CO alarm.

## KPIs
- kWh/m³ gas.
- starts.
- failed starts.
- runtime.
- trips.
