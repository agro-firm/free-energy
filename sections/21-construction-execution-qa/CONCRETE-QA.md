# Concrete QA

## Before pour
- approved mix/source.
- formation/blinding accepted.
- rebar.
- cover spacers.
- formwork.
- embedded sleeves.
- waterstops.
- construction joints.
- pour route.
- vibrator.
- weather plan.

## During
- delivery/batch record.
- workability/slump per approved ITP/spec.
- temperature if required.
- sampling/cubes/cylinders per approved engineer/specification.
- vibration.
- no uncontrolled water addition.

## After
- finish.
- curing.
- form removal.
- crack/honeycomb inspection.
- strength reports.
- repair approval if needed.

## PWD context
PWD CMP currently provides construction checklists, material-test requests and progress monitoring tools. Project QA can use similar discipline even where PWD's internal system is not contractually applicable.
