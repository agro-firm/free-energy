# Milk Room + Chiller — Operations and Maintenance

## Every milking
- wash hands/PPE
- verify tank clean
- verify temperature display
- check filter
- record milk volume
- close tank promptly

## Daily
- temperature log
- water/energy check
- wash floor
- clean handwash/sink
- inspect dispatch hose
- inspect drain
- review power-fail/high-temperature alarms

## After dispatch
- fully drain milk
- run approved CIP/cleaning
- inspect odor/residue
- dry hoses and hang hygienically
- close/cap sanitary fittings

## Weekly
- inspect gaskets
- clean condenser
- inspect drain traps
- verify hot-water performance
- inspect chemical cabinet

## Monthly
- inspect pump seals
- check agitator
- check temperature sensor against reference thermometer
- inspect electrical connections externally
- inspect door seals/screens

## Quarterly
- refrigeration service as vendor requires
- descale hot-water system if needed
- inspect sanitary pipe dead legs
- review CIP chemical consumption

## Annual
- refrigeration preventive maintenance
- electrical test
- temperature calibration
- water-quality verification
- deep sanitation review
- update buyer QA requirements

## KPIs
- milk L/day
- milk temperature after each milking
- time-to-4°C
- chiller kWh/day
- water L/day
- CIP cycles
- rejected/spoiled milk
- power-fail events
