# Gas Storage — Operations and Maintenance

## Daily
- holder %
- pressure
- visual membrane/frame check
- gas detector status
- condensate level
- unusual odor/leak
- inlet/outlet valve status

## Weekly
- inspect membrane seams visible
- inspect frame/mesh
- drain condensate
- inspect flexible connectors
- check bonding
- review high/low events

## Monthly
- test level sensor trend
- inspect pressure transmitter
- bump-test gas detector
- inspect P/V relief externally
- inspect rodent protection
- check frame anchors/corrosion
- clean enclosure without sharp tools

## Quarterly
- leak survey on valves/connectors
- gas detector calibration per vendor
- verify control thresholds
- inspect flare/vent path
- inspect lightning/earthing components

## Annual
- membrane vendor inspection
- detailed seam/abrasion check
- P/V relief service/test
- pressure/level calibration
- frame structural inspection
- gas piping inspection
- update hazardous-area review if equipment changed

## Membrane patching
Only approved material/process.
No adhesive/tape improvisation.

## Replacement planning
Track:
- UV exposure
- seam condition
- gas permeability/leak trend
- fabric brittleness
- warranty/service age

## KPIs
- average holder level
- high-high events
- low-cutout events
- flare/vent events
- gas lost
- condensate volume
- leak alarms
- membrane downtime
