# Fertilizer Processing — Solids Balance and Yield Sensitivity

## Why scenarios are necessary
Actual fertilizer solids depend on:
- real digestate TS
- real digestion solids destruction
- screw-press capture
- cake moisture
- drying losses
- any bulking material
- screening rejects

Therefore one fixed annual tonnage is not defensible before commissioning.

## Planning digestate dry solids
```
35.91 kg DS/day
```

## Scenario A — 50% capture
Captured DS:
```
35.91×0.50
=17.955 kg/day
```

Finished at 65% TS:
```
17.955/0.65
=27.62 kg/day
```

Annual:
```
27.62×365
=10.08 t/year
```

## Earlier project estimate
The earlier rough 19–22 t/year headline assumed much more complete solids recovery and did not explicitly model separator capture.

This section replaces that rough headline with capture-sensitive scenarios.

19–22 t/year could still occur only if:
- real retained dry solids are higher,
- solids capture is exceptionally high,
- bulking/compost materials are added,
- or product moisture is higher.

Do not use those earlier figures as guaranteed sales volume.
