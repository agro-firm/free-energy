# Master Drainage Integration

## Clean network
Sources:
- roofs.
- service lane if uncontaminated.
- clean tank overflow.

Destination:
- approved stormwater system/outfall.

## Dirty manure network
Cow shed/yard dirty flow:
- Section 07.
- digester path where compatible.

## Milk wastewater
CIP/chemical wastewater:
- hygienic/process drainage.
- not automatically sent to digester.

## Fertilizer
- pressate/leachate retained in Section 12 dirty network.
- no storm discharge.

## Gas condensate
Sections 08–10:
- closed dirty-process collection.
- no stormwater.

## Master hold point
One surveyed drainage drawing must show:
- invert levels.
- pipe/channel sizes.
- clean/dirty color code.
- outfalls.
- inspection chambers.
- flood backflow protection.
