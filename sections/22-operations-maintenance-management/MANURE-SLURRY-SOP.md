# Manure and Slurry SOP

## Cow shed
- verify scraper cycles.
- remove foreign objects.
- use minimal wash water.

## Section 07
Daily:
- screen.
- sump covers.
- four batch logs.
- water:dung ratio.
- faults.

## Batch baseline
```
67.5 kg dung
+67.5 L water
≈0.135 m³ slurry
```

Four/day:
```
≈0.54 m³/day
```

## Foreign material
Remove:
- plastic.
- rope.
- stones.
- bedding clumps.

## Overflow
Emergency sump is temporary containment, not routine storage.

## KPI
- kg collected/day.
- collection efficiency.
- m³ slurry.
- batch deviation.
- blockage.
