# 21 — Master Construction Execution, Schedule, Site Logistics & QA/QC

## Status
**Construction-execution framework complete. Actual mobilization remains dependent on IFC/authority/vendor release.**

## Baseline programme
- Planning duration after applicable IFC/NTP: **40 weeks**.
- Fast-track study case: ~36 weeks.
- Approval/weather/import risk case: ~48+ weeks.
- This is not a contractor contractual duration until tender/award.

## Critical path
Digester excavation/RCC → cure & watertight/gas-tight acceptance → biological startup → gas commissioning → generator load test → integrated plant trial → handover.

## Compact-site principle
The 65×95 ft site has only ~845 ft² residual functional space after permanent footprints and the 14-ft lane.

Therefore:
- large contractor office/camp: off-site/front-adjacent preferred.
- bulk material laydown: off-site/just-in-time preferred.
- no permanent storage on Section 14 lane.
- peak onsite workforce planning: ~30–35.
