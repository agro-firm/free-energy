# Generator + Electrical — Construction and Commissioning

## Preconstruction
- select biogas generator vendor
- confirm exact footprint/weight
- obtain fuel pressure/H₂S spec
- obtain exhaust backpressure/diameter
- obtain cooling airflow
- finalize ATS topology
- finalize neutral-earth scheme
- Section 10/15 interfaces
- room fire/electrical review

## Sequence
1. set out 12×14 ft room
2. foundations/slab
3. generator housekeeping pad/anchors
4. walls/roof/door
5. intake/exhaust openings
6. install exhaust sleeves
7. install earthing/bonding
8. install generator/anti-vibration mounts
9. install exhaust flex/muffler/pipe
10. install ventilation fans/louvers
11. install gas train
12. install generator breaker/ATS/ELP
13. install cables/trays
14. install battery/charger
15. install detectors/E-stop
16. controls/network
17. insulation/resistance/earth tests
18. gas leak test
19. ventilation test
20. no-load generator test
21. load-bank/controlled load test
22. ATS test
23. gas-cycle test
24. emergency grid-loss test

## Hold points
- pad anchors
- exhaust clearance
- ventilation airflow
- gas leak test
- earthing
- neutral/ATS wiring
- breaker settings
- detector calibration
- E-stop
- load-shed logic

## Commissioning
Verify:
- 230 V/50 Hz
- frequency recovery
- voltage recovery
- 4 kW stable operation
- H₂S/gas quality
- room temperature
- ventilation
- exhaust backpressure
- ATS no-overlap
- no grid backfeed
- staged motor starts
- low-gas shutdown
