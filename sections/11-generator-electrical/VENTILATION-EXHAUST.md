# Generator + Electrical — Ventilation and Exhaust

## Room volume
```
47.57 m³
```

## Heat
At 4 kW output:
```
fuel thermal≈13.33 kW
rejected≈9.33 kW
```

Assume room sensible heat after exhaust/hot-air routing:
```
≈3.27 kW
```

## Cooling airflow
For 8°C room rise:
```
≈1,220 m³/h
```

With margin:
```
≈1,500–2,000 m³/h
```

Final vendor requirement overrides.

## Airflow arrangement
South:
- low-level cool-air intake
- gross louver ~24×24 in minimum concept

North:
- high-level hot-air exhaust fan(s)
- preferably aligned with engine cooling-air discharge

Avoid short-circuiting fresh air directly from intake to fan without passing generator.

## Fan concept
Examples:
- 2 smaller industrial fans totaling ~1,500–2,000 m³/h
or
- one appropriately rated duty fan with alarm/backup strategy

Airflow, not fan diameter alone, controls selection.

## Combustion air
Estimated with 20% excess:
```
≈15 m³/h
```
which is small relative to cooling airflow.

## Engine exhaust
Must be separate from room ventilation.

Components:
- engine exhaust manifold
- flexible stainless section
- muffler/silencer
- insulated high-temperature pipe
- wall/roof penetration
- rain protection
- discharge away from air intake, people and gas equipment

Planning diameter:
- 1.5–2 inch class only as placeholder
- generator vendor backpressure/diameter governs

## CO
Install CO detector.
Any exhaust leak is a shutdown/evacuation condition.

## Temperature
Install room-temperature sensor.
High temperature:
- alarm
- stage additional ventilation if available
- reduce/stop generator if safe temperature cannot be maintained
