# Fertilizer Processing — Functional Design

## 1. Process philosophy
Section 12 reduces hydraulic volume, recovers solids and creates manageable fertilizer streams.

It does **not** assume that all digestate automatically becomes a marketable registered fertilizer.

## 2. Buffering
BT-601 stores about one day of digestate:
```
0.60/0.54
≈1.11 days
```

This allows the screw press to run once daily rather than continuously.

## 3. Screw press
Base machine:
- ~500 kg/h
- ~3 HP / 2.2 kW
- compact manure/digestate separator

Daily feed:
```
~540 kg
```

Run time:
```
540/500
≈1.08 h/day
```

## 4. Cake
Base solids-capture scenario:
```
70%
```

Planning dry solids after digestion:
```
35.91 kg/day
```

Captured:
```
35.91×0.70
=25.137 kg DS/day
```

At 30% cake TS:
```
25.137/0.30
=83.79 kg wet cake/day
```

## 5. Curing/drying
The press cake is:
- spread shallowly
- aerated/turned
- protected from rain
- dried/conditioned before bagging

If a registered compost/fertilizer specification requires longer maturation or pathogen-reduction conditions, the actual residence time must be extended or off-site curing capacity added.

## 6. Finished solids
At 65% finished TS:
```
25.137/0.65
=38.67 kg/day
```

25 kg bags:
```
38.67/25
=1.55 bags/day
```

Monthly:
```
~46 bags/month
```

## 7. Liquid digestate
Base separator liquid:
```
≈0.456 m³/day
```

Store in covered tank, sample and use according to crop nutrient demand.

Do not dump on soil/water without agronomic control.

## 8. Screening
Optional manual rotary/sieve screening after drying removes oversized fibers/debris before bagging.

## 9. Bagging
Each bag should only carry claims supported by current registration and lab data.

Possible internal labels:
- batch date
- wet/dry source
- net weight
- lab sample ID

Commercial labels require current regulatory compliance.

## 10. Finished storage
Keep bags:
- on pallets
- dry
- off floor
- under roof
- separated from fresh digestate
