# Gas Treatment — H₂S Media Management

## Media type
Baseline accepts:
- impregnated activated carbon
- iron oxide / iron hydroxide
- metal-oxide-modified media

Final selection follows supplier H₂S capacity, humidity window, pressure drop, disposal and local availability.

## Bed loading
Two vessels:
```
25 kg each
50 kg total installed
```

Normal series:
```
Lead A → Lag B
```

## Planning capacity
For sizing only:
```
0.10 kg H₂S/kg media
```

One 25 kg bed:
```
2.5 kg H₂S theoretical
```

Do not use this value instead of supplier data.

## Breakthrough
Replacement is triggered by:
- rising H₂S between beds
- final H₂S approaching alarm
- vendor operating hours/capacity
- excessive pressure drop
- wet/flooded media

## Change procedure
1. isolate vessel
2. verify alternate treated path remains available or stop gas use
3. depressurize/purge using approved gas-safe procedure
4. verify atmosphere
5. wear PPE
6. remove spent media into sealed labeled container
7. inspect distributor/screen
8. load measured fresh media
9. close/seal vessel
10. leak test
11. return as lag
12. update media log

## Media log
Record:
- supplier
- media type
- lot
- kg loaded
- date
- inlet H₂S
- outlet H₂S
- gas volume treated
- pressure drop
- date removed
- disposal/regeneration route

## Moisture
Some H₂S media needs controlled humidity; flooding is unacceptable.
Follow supplier conditions.

## Disposal
Spent sulfur-loaded media can:
- self-heat/oxidize
- contain sulfur compounds
- require controlled disposal/regeneration

Do not dump with normal feed/manure waste.
Use supplier SDS and local environmental requirements.
