# Milk Room + Chiller — Construction Plan

## Preconstruction
- confirm exact service-lane side
- confirm clean cow/milking connection
- select chiller before finalizing door and electrical supply
- confirm wastewater discharge
- confirm hot-water system
- coordinate floor drains before slab

## Sequence
1. set out 14×18 ft room
2. construct foundations/walls/roof
3. install embedded drain and utility sleeves
4. form sloped floor
5. apply hygienic non-slip floor finish
6. install coved wall bases
7. install washable wall/ceiling finish
8. install self-closing doors/insect protection
9. install drains/traps
10. install potable/hot water
11. install electrical/data
12. install ventilation
13. bring chiller through service opening
14. install milk-transfer system
15. install wash/CIP station
16. commission cold chain and washing

## Hold points
- drain location/invert before slab
- floor slope before finish
- wall/ceiling hygienic finish acceptance
- potable-water test
- hot-water temperature/flow test
- electrical/earthing test
- chiller cooling test
- milk-contact system cleanability
- wastewater flow test
- truck-hose dispatch test

## Chiller commissioning
Vendor must demonstrate:
- target temperature
- cooling time with representative load
- agitator
- alarms/controller
- leak-free milk-contact surfaces
- drain/CIP
- compressor/condenser operation

## Hygiene acceptance
Before milk enters:
- construction dust removed
- surfaces cleaned/sanitized
- pest openings sealed
- no paint/solvent odor
- drains clean
- water quality accepted
