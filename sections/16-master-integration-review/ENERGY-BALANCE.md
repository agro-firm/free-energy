# Integrated Energy Balance

## Renewable production
### Solar
```
15 kWp×3.89
=58.35 kWh/day
≈21.30 MWh/year
```

### Biogas electricity
```
8.10–9.18 m³/day×1.7946 kWh/m³
≈14.54–16.47 kWh/day gross
```

Annual:
```
≈5.31–6.01 MWh/year gross
```

### Combined gross
```
58.35+14.54 to 16.47
=72.89–74.82 kWh/day
```

Annual:
```
≈26.60–27.31 MWh/year gross
```

## Important limitation
This is generation, not net farm consumption balance.

Parasitic loads include:
- manure pumps/mixer.
- gas treatment booster.
- water pumps.
- generator ventilation.
- fertilizer press/fans.
- inverter losses.

## Known connected-load observations
The farm has more connected load than the 5 kW biogas generator can support.

Therefore:
- grid/solar main bus serves normal operations.
- generator serves only Essential Load Board.
- heavy loads are sequenced/shed.
