# Master Integration Skill

## Purpose
Section-level engineering is not sufficient by itself. This skill verifies that Sections 01–15 work together without geometric, hydraulic, electrical, process, safety, cost or construction conflicts.

## Mandatory checks
1. Plot/area balance.
2. Global X/Y/Z coordinate freeze.
3. Clean/dirty route separation.
4. Truck/service access.
5. Water balance.
6. Electrical connected-load and source topology.
7. Biogas mass/energy balance.
8. Digestate/fertilizer balance.
9. Gas safety/hazardous-area separation.
10. Stormwater vs dirty drainage.
11. Control/PLC interface matrix.
12. Construction sequencing.
13. Commissioning dependencies.
14. CAPEX scope deduplication.
15. Image consistency.

## Raw integrated planning totals
- Plot = 6,175 ft².
- Summed ground footprints + service lane = ~5,330 ft².
- Residual site function area = ~845 ft² = ~13.7%.
- Raw section-summed CAPEX:
  - Low ≈ Tk 174.17 lakh.
  - Base ≈ Tk 252.54 lakh.
  - High ≈ Tk 383.50 lakh.
These are before vendor-quote normalization and duplicate-scope removal.

## Acceptance rule
No construction issue-for-construction package is released until all HIGH risks and all geometry/interface hold points in Section 16 are closed.
