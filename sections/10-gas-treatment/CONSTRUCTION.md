# Gas Treatment — Construction and Commissioning

## Preconstruction
- confirm Section 09 outlet pressure
- obtain Section 11 generator H₂S/pressure/moisture requirements
- sample expected raw H₂S if possible
- select media
- select vessels
- select gas meter
- select gas-compatible booster
- hazardous-area review

## Sequence
1. set out 8×10 ft
2. build slab/skid and open canopy
3. earth/bond skid
4. install KO-401
5. mount V-401A/B
6. install crossover manifold
7. install MS/PF
8. install meter
9. install booster/regulator
10. install sample points/H₂S monitor
11. install condensate drains
12. install PLC/VFD/electrical outside classified zone
13. leak/pressure test
14. load media
15. purge/commission
16. verify H₂S removal
17. integrate Section 09/11 interlocks

## Hold points
- skid anchors
- gas-rated valves
- media vessel internals
- relief/isolation logic
- gas meter orientation
- booster suitability
- electrical classification
- bonding test
- leak test
- H₂S sensor calibration
- final gas-quality test

## Commissioning
### With inert/air test medium as approved
- leak test
- valve sequencing
- pressure drop
- meter signal
- booster control

### With biogas
- low flow initially
- measure inlet H₂S
- measure after lead/lag
- verify condensate
- verify treated outlet
- verify generator pressure
- log baseline ΔP

Do not send gas to engine until gas quality is accepted.
