# Working Capital

## Formula
Working Capital =
Inventory
+ Receivables
+ Minimum Cash
- Supplier Payables.

## Base planning reserve
Three months of base OPEX:
Tk5,552,500 / 4
= Tk1,388,125.

This is a conservative early-planning reserve.

## Components
- feed inventory.
- medicine/CIP.
- H2S media.
- bags/spares.
- payroll.
- milk-buyer receivables.
- utility/vendor bills.

## Cash-cycle effect
Daily/cash milk collection can reduce working capital.
30–60 day buyer payment terms materially increase it.

## Rule
Model buyer payment days explicitly.
