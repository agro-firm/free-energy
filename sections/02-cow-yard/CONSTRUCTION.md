# Cow Yard — Construction Plan

## Preconstruction
- confirm yard relation to cow-shed gate
- survey levels
- confirm dirty-drain outlet
- confirm shade posts do not clash with cattle movement
- confirm underground sleeves before pavement

## Sequence
1. set out 18 × 28 ft
2. excavate/compact subgrade
3. install drain/outlet and utility sleeves
4. install fence/gate foundations
5. install canopy foundations
6. prepare subbase
7. install reinforcement if engineer specifies
8. pour sloped non-slip concrete pavement
9. cure concrete
10. install drain grate
11. erect fence and gates
12. erect shade canopy
13. install trough/water
14. install lights/CCTV
15. test drainage and gates
16. introduce cows gradually

## Pavement
Concept 100 mm slab is used only for planning quantity. Engineer must set:
- slab thickness
- reinforcement
- concrete strength
- joints
- subbase
- edge thickening

## Hold points
- surveyed slope before concrete
- drain invert before pavement
- post foundations before backfill
- concrete finish before acceptance
- gate latch/clearance
- runoff test with water
- trough leak test
- electrical weatherproofing

## Commissioning
Flood-test the yard with controlled water and confirm:
- no ponding
- dirty runoff reaches drain
- clean canopy water remains separate
- gates swing/slide safely
- cows do not slip
