## Critical rule
Do not apply an arbitrary "deduction percentage."

Deduct only when:
- duplicated line scope is identified.
- one procurement-package owner is assigned.
- the retained package explicitly includes the shared scope.
- the superseded section allowance is recorded as a budget credit.

## Cost layers
1. CBS — cost breakdown by section/budget.
2. WBS — work/build sequence.
3. PPK — procurement package / contract.
4. PO — purchase order / subcontract.
5. CO — approved change order.

Never confuse section number with contract package.

## Vendor selection
1. technical compliance.
2. exclusions/deviations.
3. delivery/after-sales/warranty.
4. normalized evaluated cost.
5. commercial approval.

Lowest sticker price is not automatically lowest evaluated cost.

## Import rule
No generic customs percentage.
Every imported item needs:
- HS code.
- origin.
- Incoterm.
- freight/insurance.
- live NBR/Customs tariff check.
- VAT/AIT/AT/SD/CD as applicable.
- clearing/port/inland transport.
- bank/LC charges if applicable.

## Procurement hold
No PO for critical equipment until vendor submittal dimensions, utilities and interfaces are checked against Sections 01–19.
