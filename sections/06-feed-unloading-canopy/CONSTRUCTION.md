# Feed Unloading Canopy — Construction Plan

## Preconstruction
- survey Section 05 receiving door and Section 14 lane
- confirm actual delivery-truck envelope
- confirm drainage outlet
- confirm canopy does not reduce required truck lane
- coordinate feed-store threshold height
- structural design for wind/cyclone loads

## Sequence
1. set out 10×18 ft canopy
2. locate columns outside main unloading path
3. construct column footings
4. install apron subbase
5. install trench drain/outlet
6. reinforce/pour apron slab
7. create 1% outward slope
8. erect steel canopy
9. install roof/gutter/downpipe
10. install column guards/bollards
11. install electrical/light/CCTV
12. mark unloading/safety zones
13. commission drain
14. perform test truck positioning
15. test unloading with trolley/pallet equipment

## Apron
Concept:
- 125 mm RC slab ASSUMPTION
- non-slip broom finish
- flush feed-store threshold
- no sharp curb in trolley path

Engineer must design for:
- pallet load
- pallet-truck wheel loads
- occasional trolley impacts
- local soil/subbase

## Hold points
- truck/lane mock-up before foundations
- column positions
- drain invert
- slab reinforcement
- apron slope
- clear receiving-door width
- canopy clear height
- gutter/downpipe
- nighttime lighting
- truck/chock trial

## Commissioning tests
- park actual or representative truck
- verify 4 ft worker side gap where intended
- verify door can open
- move loaded trolley
- move pallet truck on level apron
- water-test roof/gutter
- water-test apron/trench
- confirm no water enters Section 05
