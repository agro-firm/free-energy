# Fertilizer + Digestate Skill

## Baseline
- Processing area: 16 × 22 ft.
- Locate downstream of digester and close to service-lane dispatch.

## Flow
Digestate → screw press/separator → solid fraction + liquid fraction.

## Solid path
Dewater → cure/compost as required → dry → screen → bag → dispatch.

## Liquid path
Covered tank → test → field use/sale/transport according to agronomic and regulatory requirements.

## Must include
Washable work floor, leachate capture, roof/rain protection, raised bag storage, scale/bagging table and trolley/forklift path if used.

## Rule
Never guarantee fertilizer mass, N-P-K grade or sale price without measured process yield and laboratory analysis.
