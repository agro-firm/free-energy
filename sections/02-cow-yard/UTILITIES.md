# Cow Yard — Utilities

## Water
Supply from Section 13 to:
- trough
- wash hose point

Concept:
- 3/4-inch class branch to yard
- isolation valve before trough
- protected pipe route outside cow impact
- water meter or zone meter preferred

Final pipe size depends on pressure and simultaneous demand.

## Dirty drainage
Uncovered yard runoff can contain manure and must not be treated as clean stormwater.

Concept route:
```
yard pavement → east linear drain → dirty collection / approved wastewater route
```

Do **not** blindly send all monsoon rainfall to the digester because excessive rainwater can dilute and overload the process. Final civil/environmental design must define:
- first-flush handling
- dirty runoff storage
- controlled transfer to Section 07 where appropriate
- high-rainfall bypass/treatment route

## Clean stormwater
Shade-canopy roof:
```
canopy → gutter → downpipe → clean stormwater
```
Keep this separate from dirty yard drainage.

## Electrical
Minimal system:
- 2 LED/floodlights concept
- CCTV
- optional gate sensor
- optional drain high-level alarm

Keep electrical boxes above splash zone and outside cow reach.

## Gas
**No raw or treated biogas piping, storage, flare or gas equipment in Section 02.**

## Data
Recommended:
- CCTV
- water meter
- optional gate contact
- optional dirty-drain level sensor
- optional temperature sensor under shade

## Utility colors
- water: cyan
- dirty runoff: brown/orange
- clean rainwater: light blue
- electrical/data: dark blue
- gas: absent
