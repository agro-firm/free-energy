# Feed Unloading Canopy — Operations and Maintenance

## Every delivery
- inspect canopy/apron
- clear drain
- check lights if dark
- position truck
- brake/chock
- keep worker escape path
- inspect feed
- remove all temporary staging after transfer

## Daily
- sweep feed debris
- remove wet forage residue
- inspect drain grate
- keep Section 05 threshold clean/dry
- remove empty bags/straps

## Weekly
- inspect wheel chocks
- inspect trolleys
- check pallet-truck wheels/forks/leaks
- inspect column guards
- clean CCTV lens
- inspect lighting

## Monthly
- grease/service pallet truck per vendor
- inspect canopy bolts/roof sheets
- inspect gutter/downpipe
- inspect slab cracks
- repaint damaged floor markings

## Monsoon
- clean gutter/trench frequently
- check wind-driven rain
- inspect roof fasteners
- stop unloading if feed cannot remain dry

## Annual
- structural visual inspection
- electrical inspection
- canopy corrosion repair
- drain maintenance
- truck swept-path review if delivery vehicle changes
- pallet-truck service

## KPIs
- unloading time
- damaged feed on receipt
- wet-feed rejection
- worker incidents
- vehicle/lane blockage time
- drain blockage
- trolley/pallet-truck downtime
