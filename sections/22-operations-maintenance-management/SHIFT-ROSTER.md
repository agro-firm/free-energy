# Shift / Coverage Roster

This is an operating concept, not a statutory working-hours schedule.

## Suggested coverage windows
### Livestock Operator A
```
04:30–12:30
```

### Livestock Operator B
```
12:00–20:00
```

Overlap:
```
12:00–12:30
```
for handover.

### Farm Manager
Typical:
```
07:30–16:30
```
plus emergency on-call rota.

### Utility Technician
Typical:
```
07:00–16:00
```
with shared after-hours alarm/on-call arrangement.

### Feed/Cleaning/Logistics
Typical:
```
06:00–15:00
```

### Night
Security/monitoring/relief arrangement:
```
20:00–04:30
```
as operationally required.

## Roster design
Actual roster must address:
- weekly rest.
- annual/sick leave.
- public holidays.
- overtime.
- night work.
- backup coverage.
- applicable Bangladesh employment requirements.

## Minimum critical backup
If one livestock operator is absent:
manager/general worker may assist only if trained; arrange relief for milking.

If utility technician is absent:
only trained basic checks are performed; specialist work is deferred/escalated.
