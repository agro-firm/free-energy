# Receiving Inspection

## Before unloading
- PO.
- packing list.
- transport damage.
- package count.

## Inspection
- model.
- serial.
- nameplate.
- voltage.
- capacity.
- accessories.
- certificates.
- manuals.
- spare parts.

## Damage
Photograph and issue NCR/claim before acceptance.

## Storage
Follow vendor requirements:
- dry.
- upright.
- temperature.
- humidity.
- battery charging.
- corrosion protection.

## Release
Equipment is not "accepted" merely because it reached site.
