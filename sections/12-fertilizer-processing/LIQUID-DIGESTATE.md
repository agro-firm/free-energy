# Fertilizer Processing — Liquid Digestate

## Base liquid production
At the 70% solids-capture scenario:
```
≈0.456 m³/day
```

This is a hydraulic planning estimate.

## Tank
Covered:
```
~2.0 m³
```

Storage:
```
2.0/0.456
≈4.39 days
```

Therefore liquid removal/use should normally occur at least every 3–4 days.

## Why cover the tank
- reduce rain dilution
- control odor
- reduce mosquito/insect entry
- reduce uncontrolled ammonia losses
- prevent accidental fall

Tank must still be safely vented.

## Sampling
Before agronomic recommendation, test as appropriate:
- pH
- EC
- total N
- ammonium-N
- P
- K
- TS/TSS
- pathogens if required
- heavy metals if commercial regulation requires

## Field use
Application rate must be based on:
- crop nutrient requirement
- soil test
- liquid nutrient analysis
- irrigation/water balance
- setback/environmental requirements

Do not apply simply by tank volume.

## Transport
Use:
- closed IBC/drum/tank
- dedicated hose/pump
- spill containment

## No storm discharge
Liquid digestate is not stormwater.
No overflow to open drain, road or surface water.

## High tank
If LT-601 high/high-high:
- stop screw press
- stop buffer transfer as needed
- alarm
- schedule field transfer/transport

## Long storage
Long storage may:
- settle solids
- create odor/gas
- change nutrients

The project therefore prefers regular removal rather than months of onsite storage.
