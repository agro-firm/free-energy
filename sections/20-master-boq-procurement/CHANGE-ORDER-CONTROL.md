# Change Order Control

## Change trigger
- vendor deviation.
- site condition.
- authority requirement.
- user change.
- design error.
- unavailable product.

## Before approval
State:
- scope.
- reason.
- technical impact.
- geometry.
- power/water/process.
- safety.
- time.
- cost.
- budget source.

## Change formula
```
Revised Forecast =
Current Forecast
+ Approved Change
- Confirmed Credit
```

## No verbal changes
No cost-bearing site instruction without written change record except immediate safety emergency, which is documented afterward.
