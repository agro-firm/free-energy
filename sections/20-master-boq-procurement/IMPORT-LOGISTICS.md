# Import and Logistics

## Imported-equipment checklist
- supplier legal name.
- country of origin.
- HS code.
- Incoterm.
- gross/net weight.
- package dimensions.
- port.
- freight mode.
- insurance.
- customs documents.
- certificates.
- battery/chemical dangerous-goods status.
- inland transport.

## Landed-cost formula
```
Landed Cost =
Supplier Price
+ Freight
+ Insurance
+ Applicable Customs Taxes/Duties
+ Port/Clearing
+ Bank/LC Charges
+ Inland Freight
+ Installation/Commissioning if owner scope
```

## Shipping documents
As applicable:
- commercial invoice.
- packing list.
- bill of lading/AWB.
- certificate of origin.
- insurance.
- test/conformity certificates.

## Heavy/large equipment
Check lane/gate before shipment:
- package dimensions.
- lifting points.
- crane/forklift needs.
