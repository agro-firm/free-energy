# Rooftop Solar — Structural and Roof Engineering

## Existing roof
Cow-shed gable:
- 26×48 ft.
- ~21° pitch.
- steel/roof structure from Section 01.

## Added dead load
Modules:
```
787.2 kg total
```

Average module-only:
```
6.34 kg/m² over full sloped roof
```

Mounting rails/clamps/cable:
planning additional allowance:
```
~2–4 kg/m² over module area
```

## Critical issue: wind uplift
Connection design must consider:
- Bangladesh wind/cyclone region.
- roof edge/corner suction.
- rail span.
- purlin spacing.
- sheet pull-out.
- corrosion.

Dead load alone is not sufficient for approval.

## Mounting
Prefer:
- clamps/fasteners into structural purlins.
- sealed penetrations.
- corrosion-compatible materials.
- no fastener only into thin roofing sheet.

## Roof warranty/waterproofing
All penetrations:
- approved flashing/seal.
- inspection.
- water test where practical.

## Structural hold point
No panel installation until structural engineer confirms:
- purlins.
- rafters/trusses.
- connections.
- foundations.
- uplift.
- added dead load.
