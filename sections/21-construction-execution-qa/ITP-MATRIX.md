# Inspection and Test Plan Matrix

Legend:
- H = HOLD: work stops until release.
- W = WITNESS.
- R = REVIEW/record.

| Activity | Check | Level |
|---|---|---|
| Survey | benchmark/setting out | H |
| Excavation | formation/soil/level | H |
| Backfill | material/lift/compaction | W |
| Rebar | size/spacing/cover/laps | H |
| Formwork | line/level/support/embedded | H |
| Concrete | mix/slump/samples/pour | W |
| Waterproof tank | coating/joints/hydrotest | H |
| Drainage | invert/slope/leak | H |
| Structural steel | material/bolts/weld/alignment | W/H |
| Roof | fasteners/seal/waterproofing | W |
| Milk finish | hygienic finish/drain | H |
| Process pipe | material/weld/joint/pressure test | H |
| Gas pipe | leak test/cleanliness | H |
| Electrical | cable/IR/earth/protection | H |
| Instrument | calibration/loop test | W |
| Solar | torque/polarity/IR/earth | H |
| Fire system | device test/cause-effect | H |
| Equipment | alignment/rotation/vendor SAT | W/H |
| As-built | location/elevation | R/H before cover |

Approved package-specific ITP can add stricter points.
