# Fertilizer + Digestate Skill

## Canonical baseline
- Processing area: **16 × 22 ft = 352 ft²**.
- Digestate inflow: **~0.54 m³/day**.
- Buffer tank: **~0.75 m³ gross**.
- Screw press: **~500 kg/h class, ~2.2 kW / 3 HP concept**.
- Liquid tank: **~2.0 m³ covered**.
- Base separator solids-capture assumption: **70%**.
- Base wet cake: **~83.8 kg/day at 30% TS**.
- Base finished product: **~38.7 kg/day at 65% TS ≈14.1 t/year**.
- 25 kg bagging.
- Service-lane dispatch.

## Yield sensitivity
Using planning digestate dry solids ~35.91 kg/day:
- 50% capture → ~10.1 t/year finished product.
- 70% capture → ~14.1 t/year.
- 90% capture → ~18.1 t/year.

Actual yield depends on digestion solids destruction, separator capture, cake moisture, curing losses and any added bulking material.

## Flow
Digestate → buffer → screw press → solid cake + liquid fraction.

Solid:
dewater → cure/dry → screen if needed → test → bag → dispatch.

Liquid:
covered tank → test → agronomic use/sale/transport.

## Regulatory rule
Commercial fertilizer sale requires current Bangladesh regulatory verification, registration/approval and product specification/testing as applicable. Farm-use digestate is not automatically equivalent to a registered commercial fertilizer product.

## Quality rule
Do not claim N-P-K, pathogen status, heavy-metal compliance, moisture or organic-matter content without laboratory results.

## Drainage rule
All pressate/leachate/wash water remains in contained dirty-process drainage; roof stormwater remains separate.
