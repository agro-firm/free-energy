# Biogas Digester — Construction and Commissioning Plan

## Preconstruction
- geotechnical/soil assessment
- highest groundwater estimate
- structural design
- buoyancy/uplift check
- final process P&ID
- hazardous-area review
- Section 07/09/12 interface elevations
- reinforcement/waterstop drawings

## Sequence
1. survey 16×20 ft compound
2. excavation/shoring/dewatering
3. subgrade preparation/blinding
4. base reinforcement and sleeves
5. cast base slab
6. cast cylindrical wall in controlled lifts
7. install construction-joint waterstops
8. cure and inspect
9. gas/water-resistant internal coating/lining
10. install feed/digestate sleeves
11. install roof/manway/gas penetrations
12. install P/V safety hardware
13. install outlet chamber
14. install recirculation loop
15. install gas/condensate interface
16. install sensors/electrical
17. backfill in controlled layers
18. construct compound paving/drainage
19. hydro/leak test
20. gas-tightness test using approved safe procedure
21. control I/O test
22. biological startup

## RCC quantity planning
Concept gross RCC:
```
~11.13 m³
```
before outlet chambers/service works.

Do not order reinforcement/concrete from this conceptual quantity.

## Watertightness
Water test before biological startup:
- inspect wall/base joints
- inspect penetrations
- monitor level loss
- correct leaks before backfill where possible

## Gas tightness
Use a safe low-pressure test method approved by the engineer/vendor.
Do not use live biogas as the first structural leak test.

## Hold points
- excavation safety
- subgrade
- base rebar/sleeves
- wall reinforcement
- waterstops
- roof reinforcement/penetrations
- internal lining
- hydrotest
- backfill
- P/V relief
- manway seal
- gas-line test
- commissioning signoff
