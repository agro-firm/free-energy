# Waste Receiving + Mixing — Cost and Budget Report

## Basis
Bangladesh planning estimate, October 2026. Section 07 only.

```

=Tk 183,300
```

```
1,222,000+183,300

```

## High-cost drivers
- industrial chopper/solids pumps
- slurry-rated electromagnetic meter
- PLC/HMI/remote monitoring
- underground waterproof RCC
- duty/standby pump redundancy
- stainless components
- gas/H₂S monitoring
- poor groundwater/soil conditions

## Exclusions
Cow-shed scraper system, Section 08 digester, main water utility, plant-wide SCADA/server, gas system, land and permit/professional fees unless quoted.

## Procurement
Get vendor data for:
- solids size
- pump curve
- mixer torque
- tank/load-cell accuracy
- flow-meter liner/electrode compatibility
- valve bore
- PLC I/O
before purchase.
