# Truck / Service Lane — Operating Process

## Arrival
1. confirm node available
2. gate opened
3. spotter assigned
4. pedestrians/animals cleared
5. truck enters/reverses according to site procedure
6. truck stops at marked node
7. parking brake/chocks

## Milk
- connect sanitary hose
- transfer
- disconnect/cap
- clean node
- truck departs

## Feed
- align Section 06
- unload
- inspect feed
- clear lane immediately

## Fertilizer
- pallet/liquid system prepared before truck arrival
- load without dirty spill
- close/secure load
- clean lane

## Departure
- remove chocks
- spotter clear signal
- forward exit preferred
- gate closes
- node recorded clear

## Conflict rule
Milk and fertilizer handling must not occur simultaneously if traffic/hygiene paths conflict.
