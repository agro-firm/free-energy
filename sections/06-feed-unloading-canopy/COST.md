# Feed Unloading Canopy — Cost and Budget Report

## Basis
Bangladesh planning estimate, October 2026. Section 06 only.

## Current public references
- City Steel 2026 guide: basic industrial shed/warehouse roughly Tk400–600/ft².
  https://citysteelbd.com/blogs/steel-structure-building-cost-in-bangladesh-2026
- Billal Steel 2026 guide: full single-story shed rates can be substantially higher depending on span/specification.
  https://www.billalsteel.com/blogs/steel-structure-building-cost-in-bangladesh-2026
- BDStall September 2026 hand-pallet references:
  - Equipmax HPT30 3-ton hand pallet truck ~Tk38,500
  - Hydraulic hand pallet ~Tk30,000
  - 300 kg folding platform trolley ~Tk5,500
  https://www.bdstall.com/hand-pallet-truck/

Because this is a **small canopy**, fixed fabrication/mobilization costs make its per-ft² rate higher than a very large shed. Base canopy allowance uses Tk650/ft².

12% contingency:
```
356,000 × 0.12
= Tk 42,720
```

Base total:
```
356,000 + 42,720
= Tk 398,720
≈ Tk 3.99 lakh
```

## High-cost drivers
- stronger cyclone/wind structure
- deeper/poor-soil foundations
- heavier vehicle/pallet apron design
- premium galvanized structure
- complex drainage
- optional stacker/forklift
- truck dock/tail-lift infrastructure
- higher-grade lighting/security
