# Procurement Risk Register

| Risk | Action |
|---|---|
| Vendor exclusions hidden | mandatory deviation schedule |
| Imported item customs surprise | HS/landed-cost sheet |
| FX movement | quote validity/FX basis |
| Vendor dimensions clash | submittal gate before PO/foundation |
| Long lead delays | early RFI/lead-time register |
| Poor local support | after-sales evaluation |
| Duplicate scope | master ownership/dedup register |
| Warranty void from third-party install | supply+install where needed |
| Advance-payment risk | commercial security/milestones |
| Counterfeit/substitute model | serial/model receiving inspection |
| Unapproved solar/fire equipment | current approval-list check |
| Consumable lock-in | annual media/spares pricing |
