# Generator + Electrical — Operations and Maintenance

## Every run
- gas available/quality
- oil level
- battery voltage
- ventilation
- CH₄/CO alarms
- room clear
- breaker/ATS status

## Daily/when used
- runtime
- kWh
- average load
- gas m³
- room temperature
- unusual vibration/noise
- exhaust leak
- oil leak

## Weekly
- battery charger
- gas valve/flex inspection
- fan/louver cleaning
- E-stop visual check
- panel alarm history

## Monthly
- exercise generator if not run
- test ATS
- inspect exhaust supports
- clean air filter
- check spark plug/ignition as vendor specifies
- check anti-vibration mounts
- test CH₄/CO alarms

## Service interval
Follow generator vendor for:
- engine oil
- spark plug
- valve clearance
- air filter
- alternator
- starter
- battery

Do not substitute diesel-generator service intervals automatically.

## Quarterly
- electrical thermal/visual inspection
- earth/bond inspection
- meter reconciliation gas vs kWh
- load-shed test
- ventilation airflow check

## Annual
- licensed electrical inspection
- ATS service
- detector calibration
- exhaust/muffler inspection
- generator major service per hours
- insulation/earth tests
- backup control logic test

## KPIs
- kWh/m³ gas
- runtime/day
- average kW
- starts/day
- failed starts
- load-shed count
- gas-quality trips
- room high-temperature events
- maintenance cost/kWh
