# Gas Storage — Construction and Commissioning

## Preconstruction
- select membrane vendor
- confirm 8 m³ actual bag dimensions
- confirm allowable pressure/vacuum
- confirm membrane material/H₂S compatibility
- hazardous-area review
- vent/flare route
- lightning/earthing review
- foundation/anchor design
- Section 08/10 line elevations

## Sequence
1. set out 10×12 ft zone
2. construct reinforced raised slab
3. install earth/bond points
4. erect protective galvanized frame
5. remove/protect all sharp edges
6. install gas manifold/condensate
7. install P/V safety line
8. install level/pressure/gas detection
9. install membrane on clean protective surface
10. connect flexible inlet/outlet
11. install mesh/removable panels
12. perform instrument I/O test
13. leak/pressure test with approved inert/air procedure per vendor
14. purge/commission with biogas safely
15. test high/low level logic
16. test P/V protection
17. hand over documentation

## Membrane installation
- no dragging over concrete
- clean surface
- no sharp footwear/tools
- use lifting/support methods approved by vendor
- avoid twisting connectors

## Leak test
Do not overpressurize.
Vendor defines:
- test medium
- test pressure
- hold time
- acceptable leak criteria

## Commissioning
Verify:
- holder level calibration
- pressure calibration
- inlet/outlet valve function
- condensate drain
- CH₄/H₂S alarms
- low cutout
- high/high-high logic
- flare/vent permissive
- upstream/downstream interlocks

## Hold points
- slab/anchors
- frame sharp-edge inspection
- membrane certificate
- gas piping pressure/leak test
- P/V relief certificate
- earth/bond test
- gas detector bump/calibration
- final gas-safe commissioning
