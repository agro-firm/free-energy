## Method
LGED drainage references use the Modified Rational method for small catchments:
```
Q = Cr × Cs × i × A / 360
```
where:
- Q m³/s.
- Cr runoff coefficient.
- Cs storage coefficient.
- i rainfall intensity mm/h.
- A hectares.

## Screening case only
Assume:
- Cr=0.90.
- Cs=1.00.
- i=100 mm/h.
- A=0.057368 ha.

```
Q=0.90×1×100×0.057368/360
=0.01434 m³/s
=14.34 L/s
```

This is not the final design storm.

## Final hydrology
Civil engineer selects:
- return period.
- time of concentration.
- Khulna/local IDF intensity.
- weighted runoff/storage coefficients.
- climate/flood/backwater allowance.

## Catchment separation
Calculate separately:
- roofs.
- lane/paved clean areas.
- open/pervious buffers.
- dirty process areas that do not discharge to stormwater.
