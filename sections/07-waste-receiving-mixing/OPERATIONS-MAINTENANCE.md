# Waste Receiving + Mixing — Operations and Maintenance

## Daily
- inspect coarse screen
- inspect sump covers
- review 4 batch logs
- check dung kg/day
- check water L/day
- check slurry m³/day
- inspect leaks/splashes
- inspect emergency sump level
- verify pump/mixer faults

## Every batch
Automatic log:
- dung mass
- water volume
- mix duration
- slurry volume
- pump runtime
- deviations

## Weekly
- clean coarse screen/basket
- remove grit
- inspect check valves
- inspect load-cell zero
- flush/inspect flow meter as vendor allows
- inspect vent/odor path
- test E-stop

## Monthly
- inspect pump impellers
- inspect mixer gearbox/coupling
- compare water meter vs tank/load balance
- verify high/high-high level alarms
- test emergency-sump alarm
- inspect pipe supports/valves
- review energy/runtime trends

## Quarterly
- calibrate/load-check MT-101 weighing
- verify FIT-301 against controlled volume if possible
- electrical panel inspection
- inspect sump waterproofing from above
- clean process surfaces thoroughly

## Annual
- pump major service
- mixer service
- flow-meter calibration/verification
- PLC backup
- sensor replacement review
- structural/sump inspection
- full cause/effect test

## Spare parts
Keep:
- pump seal/impeller kit or quick-change spare pump
- float/level sensor
- solenoid valve coil
- motor contactor/overload
- check-valve service parts
- screen basket spare mesh
- fuses
- load-cell junction parts

## KPIs
- collection efficiency
- batch completion %
- water:dung ratio
- m³ slurry/day
- kWh/m³ slurry
- blockage events
- emergency-sump uses
- average batch deviation
