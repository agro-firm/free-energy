# Solar Skill

## Baseline
- Target: 15 kWp.
- Location: cow-shed roof.
- Ground footprint: zero unless a later approved change adds ground mount.

## Required calculations
- Panel wattage and count.
- Real module dimensions and roof packing.
- Maintenance access.
- Roof structural load.
- String voltage/current.
- Inverter sizing.
- Cable sizing and voltage drop.
- Earthing/lightning protection.
- Expected yield using verified local solar resource.

## Rule
Do not draw panels beyond roof edges or over required vents/access paths.
