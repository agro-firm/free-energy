# Truck / Service Lane — Engineering Math Workbook

## 1. Area
```
14×95
=1,330 ft²
```

```
1,330×0.09290304
=123.561 m²
```

## 2. Reference vehicle
Tata LPT 709 long version:
```
width=2.155 m=7.07 ft
length=6.875 m=22.56 ft
GVW=7,500 kg
```

## 3. Centered clearance
```
14-7.07
=6.93 ft total
```

```
6.93/2
=3.46 ft each side
```

## 4. Loading-side positioning
Provide 4 ft worker gap:
```
14-4-7.07
=2.93 ft outer clearance
```

## 5. Turning
Reference turning-circle diameter:
```
12.3–13.5 m
≈40.35–44.29 ft
```

Since lane width is only 14 ft, internal U-turn is impossible.

## 6. Crossfall
```
14×1.5%
=0.21 ft
=2.52 in
```

## 10. Pavement loading
7.5-t GVW is the minimum planning vehicle basis.
Actual axle loads, tire pressure, traffic repetitions and subgrade CBR govern final pavement.
