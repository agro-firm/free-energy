# Breakdown and Escalation

## P1
Safety/animal/milk/gas/water critical.
Response:
immediate safe state + manager + specialist.

## P2
Production degraded but safe.
Response:
same shift, temporary safe workaround only if approved.

## P3
Noncritical.
Planned repair.

## Work order
Record:
- asset.
- symptom.
- alarm.
- downtime.
- action.
- parts.
- root cause.
- restart verification.

## Repeat failure
Three similar failures or adverse trend triggers root-cause review rather than repeated reset/repair.

## Temporary bypass
Must have:
- risk assessment.
- owner.
- expiry.
- monitoring.
- restoration plan.
