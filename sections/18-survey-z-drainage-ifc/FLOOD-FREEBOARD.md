# Flood and Freeboard Framework

## Flood reference
Define:
```
FRL = max(
verified authority/design flood level,
credible observed flood/high-water mark,
hydraulic backwater level,
site-specific flood study
)
```

## Internal planning freeboards
Not statutory values:
- normal clean/dry building: +300 mm above FRL.
- generator/electrical critical room: +450 mm above FRL.
- water-tank access/manhole: +300 mm.
- gas/process slabs: +300 mm where practical.
- livestock wet areas: engineer sets safe contained level.

## Why
BMD climate analysis for Khulna shows heavy to very heavy rainfall is a recurring monsoon condition, and recent Bangladesh flood bulletins have also reported heavy rainfall in Khulna Division.

## Do not
- set FFL solely from road crown.
- use one anecdotal water mark without verification.
- assume drainage outfall remains free during peak rainfall.

## If no reliable flood data
Use conservative survey/hydraulic analysis and local professional judgment; document the adopted basis.
