# Fertilizer Processing — Architecture Report

## 1. Design intent
Section 12 is a **covered, ventilated, washable processing shed** that converts daily digestate into two controlled streams:
- dewatered solid fertilizer material
- liquid digestate

It is not a long-term bulk compost yard.

## 2. Geometry
```
16×22=352 ft²
352×0.09290304=32.7019 m²
```

Local:
- X=0–22 ft west→east
- Y=0–16 ft south→north
- west receives Section 08 digestate
- south/east interfaces with service lane/loading

## 3. Four zones
### Receiving/separation — X 0–6
```
6×16=96 ft²
```
Includes:
- covered digestate buffer
- separator feed pump
- screw press
- cake chute
- liquid outlet

### Curing/drying — X 6–14
```
8×16=128 ft²
```
Includes:
- four 4×8 ft bays or equivalent removable bins
- aeration/turning space
- fans/open ventilation
- leachate collection

### Bagging/finished — X 14–18
```
4×16=64 ft²
```
Includes:
- screening table/sieve
- weighing
- 25 kg bags
- sewing/sealing
- palletized finished stock

### Liquid/service — X 18–22
```
4×16=64 ft²
```
Includes:
- ~2.0 m³ vertical liquid tank
- pump/valves
- sampling
- hose/loading connection

## 4. Roof
Concept gable/open-sided roof:
- eave ~10 ft
- ridge ~13 ft
- 16 ft span

Half span:
```
8 ft
```

Rise:
```
3 ft
```

Angle:
```
arctan(3/8)
≈20.56°
```

Approximate sloped roof area:
```
352/cos(20.56°)
≈376 ft²
```

10% allowance:
```
≈414 ft²
```

## 5. Floor
- reinforced concrete
- non-slip washable finish
- curbed dirty-process edges
- floor slopes to leachate/process drain
- bagging area kept dry and raised
- no dirty liquid crossing finished-bag path

## 6. Drying architecture
The 128 ft² curing zone is roofed but naturally ventilated.

Base cake:
```
~83.8 kg/day
```

Seven-day wet cake:
```
≈586.5 kg
```

Curing area:
```
128 ft²=11.89 m²
```

Average 7-day loading:
```
586.5/11.89
≈49.3 kg/m²
```

This fits shallow covered drying/curing beds.

## 7. Liquid tank
Planning cylinder:
- diameter ~1.2 m
- liquid height ~1.8 m

```
π×0.6²×1.8
≈2.04 m³
```

Use a covered vented tank with service access.

## 8. Ventilation
Natural cross ventilation is primary.
Two small circulation/exhaust fans may be added for drying/humidity.

## 9. Separation from clean areas
No milk, feed or office flow crosses Section 12.

## 10. Dispatch
Finished bags and liquid tanker/drum transfer should be directly accessible from the service lane without crossing digester/gas equipment.
