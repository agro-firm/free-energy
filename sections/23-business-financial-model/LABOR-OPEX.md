# Labor and Staffing Cost

## Staffing
Section 22 core:
- farm/operations manager: 1.
- livestock/milking operators: 2.
- utility/process technician: 1.
- feed/cleaning/logistics worker: 1.

## Base illustrative financial input
Tk1,500,000/year
= Tk125,000/month total payroll allowance.

This is not a current salary quotation.

## Include in final payroll
- salary/wage.
- overtime.
- bonus/benefit where applicable.
- relief/leave coverage.
- security/night coverage.
- specialist service labor.
- statutory/payroll obligations where applicable.

## Rule
Do not use casual daily-wage benchmarks as final skilled manager/technician payroll.
