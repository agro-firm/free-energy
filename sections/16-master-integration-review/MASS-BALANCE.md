# Integrated Mass and Product Balance

## Milk
Planning:
```
14 lactating cows×10 L/day
≈140 L/day
```

## Feed
Reference:
```
20×12 kg DM/day
=240 kg DM/day
```

Separate storage assumptions:
- concentrate ~60 kg/day.
- dry roughage ~80 kg/day.
- fresh forage ~300 kg/day as-fed.

Do not sum as-fed and dry-matter values as if equivalent.
