# Office + Vet + Biosecurity — Operating Process

## 1. Staff entry
```mermaid
flowchart LR
    Outside --> Footwear[Footbath / Shoe Change]
    Footwear --> PPE[Clean PPE]
    PPE --> Wash[Handwash]
    Wash --> Office[Office / Farm Side]
```

## 2. Visitor entry
1. sign visitor log
2. confirm reason for entry
3. apply footwear/PPE protocol
4. handwash
5. remain escorted if required
6. record exit

Visitors should not move directly from outside to animal areas without this sequence.

## 3. Veterinary work
```
records → prepare instruments/medicine → perform farm/animal task → return instruments → segregate sharps/waste → clean/disinfect → update records
```

## 4. Artificial insemination
- confirm animal ID and breeding record
- prepare AI equipment
- retrieve semen from LN₂ tank per trained procedure
- perform procedure in appropriate animal handling area, not inside office
- return/store equipment
- record sire/batch/date/technician

## 5. Vaccine receipt
- verify package temperature/condition
- record product, lot and expiry
- move promptly into 2–8°C refrigerator
- do not overpack refrigerator
- log temperature

## 6. Vaccine/medicine issue
- authorized person only
- FEFO: first-expire, first-out
- record animal, product, dose, batch, date and administrator
- return cold-chain product promptly
- segregate expired/damaged product

## 7. Temperature excursion
If fridge leaves approved range:
- quarantine affected stock
- do not assume it is usable
- record time/temperature
- consult product manufacturer/veterinary guidance
- restore cold chain
- investigate power/fridge fault

## 8. Power failure
- fridge remains closed
- local UPS bridges outage
- plant backup starts
- alarm/notification
- monitor logger

## 9. Sharps/biological waste
Sharps → puncture-resistant container.
Biological/vet waste → labeled controlled container.
Never mix with normal office waste.

## 10. Records
Maintain:
- visitor log
- herd treatments
- vaccines
- medicine inventory
- withdrawal periods if relevant
- breeding/AI records
- fridge temperature
- equipment maintenance
- incidents/biosecurity breaches
