# Cost Reporting

## Monthly dashboard
- Original Budget.
- Approved Budget Transfers.
- Current Budget.
- Committed.
- Invoiced.
- Paid.
- Forecast to Complete.
- Forecast at Completion.
- Variance.

## Formula
```
FAC = Committed + Forecast Uncommitted + Approved Risk/Changes
```

## Section and package views
Report both:
- by CBS section.
- by PPK contract.

## Dedup credits
Show explicitly as:
- original allowance.
- superseding package.
- approved credit.

Never silently erase the original history.
