# Truck / Service Lane — Architecture and Site Design

## 1. Purpose
This 14-ft-wide strip is productive shared infrastructure, not leftover land. It combines:
- truck movement
- milk pickup
- feed delivery
- fertilizer loading
- veterinary/service access
- process-equipment maintenance access
- controlled emergency access

## 2. Geometry
```
14×95 = 1,330 ft²
```

```
1,330×0.09290304
=123.561 m²
```

## 3. Physical form
- flush rigid-pavement lane
- no raised center islands
- loading doors/canopies on building side
- outer-edge drain
- no permanent equipment within 14-ft clear corridor
- gate/entry flare at front
- bollards only outside swept vehicle envelope

## 4. Width management
The entire 14 ft remains physically traversable.

Painted operational layout at loading nodes:
- ~4 ft worker/loading side
- ~7.07 ft actual design-truck width
- ~2.93 ft outer clearance

Check:
```
4 + 7.07 + 2.93 = 14 ft
```

The 4-ft strip is painted/operational, not a continuous raised sidewalk.

## 5. Loading-node architecture
### Milk node
- chiller dispatch door directly faces lane
- truck transfer hose stays short
- clean area
- no manure/fertilizer crossing

### Feed node
- aligned with Section 06 canopy
- truck side-unloads into covered apron
- rain protection
- no long-term lane blockage

### Rear node
- fertilizer bag/liquid transfer
- generator/digester maintenance
- dirty spill containment stays inside Section 12/utility process areas

## 6. Gate
Minimum:
```
14 ft clear
```

Preferred:
```
16 ft clear
```
if boundary flare allows, because angled entry consumes side clearance.

## 7. Vertical clearance
Main lane remains open to sky wherever possible.
Planning minimum unobstructed height:
```
≈4.2 m / 13.8 ft
```
where overhead elements exist.

Final fire/emergency criteria may require different clearance.

## 8. Lighting
Use wall/pole lights positioned outside truck strike zone.
Avoid low fixtures/cables over lane.

## 9. Landscaping
No tree trunk, planter, drain cover or signage post intrudes into vehicle envelope.

## 10. Fire/emergency
The lane may support emergency access, but must not be labeled as code-compliant fire access until current local Fire Service/BNBC requirements and entrance/swept path are verified.
