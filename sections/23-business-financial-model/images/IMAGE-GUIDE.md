# Section 23 AI Image Guide

Create professional financial dashboards and business-model infographics.

Use exact scenario values from SCENARIO-RESULTS.csv.

Label all scenario values as illustrative.

Do not use packaged retail milk price as the base farm selling price.

Do not claim profitability in the base case.

Suggested visual status:
- negative EBITDA: warning/red.
- break-even: neutral.
- positive scenario: green.
