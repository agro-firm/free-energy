# Quote Normalization

## Evaluated cost
```
Evaluated Cost =
Quoted Price
+ required excluded scope
+ freight/insurance
+ clearing/inland transport
+ taxes/duties where owner bears them
+ required installation
+ commissioning
+ mandatory spares
+ interface modification
- confirmed discounts/credits
```

## Normalize
- currency.
- quantity.
- unit.
- capacity.
- warranty.
- delivery.
- scope boundary.
- tax basis.

## Example
Vendor A includes installation; Vendor B excludes installation.
Do not compare their quoted totals directly.

Add the missing installation budget to Vendor B before commercial ranking.
