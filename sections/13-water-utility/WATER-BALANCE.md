# Water Utility — Water Balance

## Normal daily demand
| Use | L/day |
|---|---:|
| 20 cows drinking | 1,600 |
| Cow shed + yard washdown | 700 |
| Milk room cleaning/CIP | 396.82 |
| Office/vet | 80 |
| Digester dilution | 270 |
| Fertilizer/process wash | 100 |
| Staff/general | 150 |
| **Total** | **3,296.82 L/day** |

```
=3.297 m³/day
```

## Design margin
15%:
```
3.29682×1.15
=3.79134 m³/day
```

## Hot-weather case
If cow drinking rises to 100 L/cow/day:
```
20×100=2,000 L/day
```

Adds 400 L/day:
```
3.69682×1.15
=4.25134 m³/day
```
