# Rooftop Solar — Automation and Monitoring

## Log
- DC voltage/current per MPPT.
- inverter AC kW.
- daily kWh.
- monthly kWh.
- lifetime kWh.
- grid voltage/frequency.
- inverter temperature.
- alarms.
- export/import if meter data available.

## Alarms
- string underperformance.
- insulation fault.
- SPD alarm.
- grid over/under voltage.
- overtemperature.
- communication loss.

## Performance
Compare Plane A vs Plane B.
Large unexplained deviation may indicate:
- shade.
- dirt.
- connector fault.
- module fault.
- orientation difference.

## Dashboard
Show:
- current solar power.
- today energy.
- month energy.
- generator energy.
- combined renewable energy.
