# Procurement Document Control

## Numbering
Example:
```
FE-PPK07-RFQ-001
FE-PPK07-SD-001
FE-PPK07-TBE-001
FE-PPK07-PO-001
```

## Registers
Maintain:
- RFQ.
- bid receipt.
- clarification.
- TBE.
- CBE.
- submittal.
- PO.
- NCR.
- inspection.
- invoice.
- warranty.

## Version
Never evaluate two vendors against different specification revisions.

## Approval
Record:
- prepared.
- reviewed.
- approved.
- date.
