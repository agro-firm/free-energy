# Fertilizer Processing — Engineering Math Workbook

## 1. Area
```
16×22=352 ft²
352×0.09290304=32.7019 m²
```

## 2. Digestate flow
```
0.54 m³/day
≈540 kg/day planning
```

## 3. Dry solids after digestion
Initial dung TS:
```
270×0.19
=51.3 kg/day
```

Assume 70% dry solids remain after digestion:
```
51.3×0.70
=35.91 kg/day
```

This is an ASSUMPTION to verify by sampling.

## 4. Base 70% separator capture
```
35.91×0.70
=25.137 kg DS/day
```

## 5. Wet cake
At 30% TS:
```
25.137/0.30
=83.79 kg/day
```

## 6. Liquid fraction
Approximate:
```
540-83.79
=456.21 kg/day
≈0.456 m³/day
```

## 7. Liquid tank storage
```
2.0/0.456
=4.39 days
```

## 8. Finished product
At 65% TS:
```
25.137/0.65
=38.67 kg/day
```

Annual:
```
38.67×365
=14,114.6 kg/year
≈14.1 t/year
```

## 9. 25 kg bags
Daily:
```
38.67/25
=1.55 bags/day
```

Monthly:
```
38.67×30/25
=46.40 bags/month
```

## 11. Screw-press electricity
Assume:
```
2.2 kW×1.08 h
=2.38 kWh/day
```

Fans:
```
2×0.25 kW×6 h
=3.0 kWh/day
```

Bagging/scale/controls:
```
≈0.2 kWh/day
```

Planning:
```
≈5.6 kWh/day
```

These loads are noncritical and normally use grid/solar, not the 5 kW biogas generator.
